VSA Design System

Atoms and tokens of the default theme. Screens use only these parts.

Atoms

Each atom is a web component in components/. It reads only its component tokens from tokens/component.css. Use the mouse or the keyboard: Tab moves the focus, Space changes a toggle. The log shows the last event.

Component tokens

The values in tokens/component.css. Each value refers to an alias token. Change one line to change that part in each atom.

Global colors

Name rule: <family>-<n>, n = 1000 − 10 × L* (CIELAB lightness), rounded to the nearest 5. A higher number is a darker color.

Check against the reference

The check compares alpha at 8 bits, the precision that the screen draws. The browser applies each alias or component token and the matching value of reference/default.css or of the Runner Studio CSS to two test elements, then compares the calculated values. Light and dark use the data-theme attribute. If the system theme is dark, the check also tests the prefers-color-scheme block.
