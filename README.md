# Umpire

Umpire checks the architecture of an app after each build. Its first architecture pack is VSA (Vertical Slice Architecture). This repository has the framework, the rule engine, the `umpire` tool and the architecture rules. The reference apps are in the consumer repos (`docs/consumers.md`).

Umpire is a working name. The terms are in `docs/vocabulary.md`, and the layout is in `docs/framework-layout.md`.
